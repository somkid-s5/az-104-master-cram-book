1. Azure มี 2 ภาพที่ต้องแยกให้ออก

เวลาข้อสอบพูดถึง Region/Zone กับ Subscription/RG อย่าจำปนกัน เพราะตอบคนละคำถาม

PHYSICAL INFRASTRUCTURE

Resource ทำงาน “อยู่ที่ไหน”

Geography
└── Region
    └── Availability Zone
        └── Datacenter

ใช้คิดเรื่องตำแหน่ง, latency, data residency และความทนต่อ Datacenter/Zone/Region failure

MANAGEMENT INFRASTRUCTURE

Resource ถูก “บริหารอย่างไร”

Management Group
└── Subscription
    └── Resource Group
        └── Resource

ใช้คิดเรื่อง Scope, RBAC, Policy, Billing, Quota และการจัดกลุ่ม Resource

ภาพจำ: Region/Zone = “อยู่ที่ไหนและล่มระดับไหน” • Management Group/Subscription/RG = “ใครบริหาร อะไรครอบอะไร และค่าใช้จ่ายอยู่ตรงไหน”

2. ต่อ Identity เข้ากับ Azure Resource

Microsoft Entra Tenant จัดการ Identity ส่วน Subscription เป็นขอบเขต Azure Resources/Billing แล้วใช้ Azure RBAC เชื่อมคนหรือ workload ให้มีสิทธิ์บน Scope ที่ต้องการ

Microsoft Entra Tenant
├── Users / Groups / Apps
│        │
│        └── Azure RBAC Role Assignment
│                    ↓
└── Azure Subscription
    └── Resource Group
        └── Resource
อย่าปน: Microsoft Entra Role = สิทธิ์จัดการ Directory/Identity • Azure RBAC Role = สิทธิ์จัดการ Azure Resources

3. Cloud Shell ใช้ยังไงในระบบเรียนนี้

Cloud Shell เป็นเครื่องมือผ่าน Browser และเลือก Bash หรือ PowerShell ได้ ตัว session เป็น environment ชั่วคราว ดังนั้นไฟล์ที่ต้องเก็บควรใช้พื้นที่ persistent/CloudDrive ตามการตั้งค่าของ Cloud Shell

USE IT FOR

ทำ Lab โดยไม่ต้อง setup เครื่องเยอะ

เช็ก subscription context, รัน Azure CLI/PowerShell, validate resource state และเก็บ evidence จากคำสั่ง

BEFORE EVERY LAB

เช็ก Context ก่อนสร้างหรือลบ

az account show
az account list -o table

หลักคือรู้ให้ชัดว่า Account / Tenant / Subscription ที่กำลังใช้อยู่คือตัวไหนก่อนเปลี่ยน Resource
