CONTAINER APPS

Revision + traffic + scale mental model

REVISIONImmutable snapshot

Version-changing updates create a new revision. Multiple revisions can be active depending on revision mode.

TRAFFICSplit between revisions

Use traffic weights for blue/green or A/B style rollout.

SCALEPer-revision replicas

Scale rules add/remove replicas. Min replicas can be zero for many workloads.

ENVIRONMENTShared boundary

Container Apps live inside an environment that provides networking/logging/isolation boundary.
